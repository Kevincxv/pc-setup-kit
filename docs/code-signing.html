Code signing policy

For the Messiah installer (Install-Messiah.exe) of the open-source pc-setup-kit project.

Who signs

Free code signing provided by SignPath.io, certificate by SignPath Foundation (applied for; until it is granted the installer is not signed).

Only the installer built from this repository's source by GitHub Actions (.github/workflows/sign.yml, from tools/installer/Installer.cs) is signed, and only for published releases. Nothing built on a personal computer is ever signed.

Team roles

  • Committers and reviewers: the repository's maintainers (contributors).
  • Approvers: the owner of the repository, who approves each signing request.

All team members use multi-factor authentication for GitHub and SignPath.

Privacy

This program does not send personal information anywhere. It only connects to the internet to do what it is for: downloading Windows, driver and app updates from their makers (Microsoft, winget, NVIDIA, AMD, Intel, the PC maker), and newer versions of itself from this project's GitHub releases. The optional AI assistant (Claude) is only used after the owner signs in with their own Claude account, and is subject to Anthropic's privacy policy.
